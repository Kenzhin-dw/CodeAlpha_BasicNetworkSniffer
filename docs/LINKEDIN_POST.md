# LinkedIn Post

I have completed Task 1, **Basic Network Sniffer**, as part of the CodeAlpha Cyber Security Internship.

For this task, I built a Network Packet Sniffer and Traffic Analyzer for authorized monitoring on Windows. The application uses Scapy and Npcap to capture packets, converts IPv4 and IPv6 traffic into structured metadata, and displays the results in a Streamlit dashboard.

Key parts of the project include:

- Background packet capture with a thread-safe, bounded in-memory buffer
- TCP, UDP, ICMP, DNS, HTTP-like, and HTTPS/TLS metadata classification
- Live packet tables, traffic metrics, protocol charts, endpoint rankings, and a timeline
- Protocol and IP filters
- Privacy-conscious payload handling and metadata-only CSV export
- Synthetic automated tests for parsing, statistics, and export behavior

This project helped me understand how network packets move from an interface into protocol-aware structured data, and how capture tools should handle privacy, permissions, and encrypted traffic responsibly.
