# CodeAlpha Submission Form Guide

This repository represents **Task 1 — Basic Network Sniffer**.

## LinkedIn Video Explanation Post Link (Task 1)

Paste the URL of the specific published LinkedIn post that contains your technical project video.

Correct destination:

```text
The published LinkedIn post containing the video
```

Do not paste:

- your LinkedIn profile URL
- a local video filename
- a draft-post URL
- the GitHub repository URL

Before submitting, open the LinkedIn post URL in a private/incognito browser window and verify that the post and video are accessible with the intended visibility.

## GitHub Repository Link (Task 1)

Paste the URL of the public or otherwise CodeAlpha-accessible project repository.

Expected format:

```text
https://github.com/<username>/<repository>
```

Do not paste:

- your GitHub profile URL, such as `https://github.com/<username>`
- a local folder path
- a ZIP filename
- a link to only one source file
- the LinkedIn post URL

Before submitting, open the repository URL in a private/incognito browser window and verify that the README, source, tests, and documentation are accessible.

## Final form review

1. Select the correct task number: **Task 1**.
2. Paste the LinkedIn post URL into the LinkedIn field.
3. Paste the GitHub repository URL into the GitHub field.
4. Open both links from the form preview if the form makes them clickable.
5. Check spelling and make sure the two URLs were not exchanged.
6. Review all other required personal or internship fields.
7. Submit the form manually only after the checks pass.
